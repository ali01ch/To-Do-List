# روزنو

برنامه محلی مدیریت کار، با رابط فارسی و چیدمان راست‌به‌چپ. اطلاعات روی همین دستگاه و در IndexedDB می‌ماند. این نسخه پایه است و هنوز ثبت کار را در رابط نشان نمی‌دهد.

## وضعیت

مرحله ۱ انجام شده است: اسکلت برنامه، پوسته موبایل و دسکتاپ، تم روشن و تاریک، و لایه دسترسی به داده.

هنوز این‌ها ساخته نشده‌اند و در رابط به‌عنوان قابلیت آماده نشان داده نمی‌شوند:

- ثبت، ویرایش و تکمیل کار
- فهرست، برچسب، جست‌وجو و فیلتر
- تقویم، تکرار، تمرکز و آمار
- یادآوری، خروجی و بازیابی، و نصب PWA

## اجرا

```bash
npm install
npm run dev
npm test
npm run build
```

## معماری

رابط از Pinia به Repository و از آنجا به Dexie می‌رسد. کامپوننت‌ها مستقیم به IndexedDB وصل نمی‌شوند.

تاریخ سررسید بدون ساعت با قالب `YYYY-MM-DD` ذخیره می‌شود و با زمان دقیق یک رویداد قاطی نمی‌شود. نمایش شمسی فقط در لایه نمایش است.

انتخاب ظاهر در IndexedDB ذخیره می‌شود. یک رونوشت کوچک در `localStorage` فقط برای جلوگیری از چشمک‌زدن رنگ پیش از بارگذاری پایگاه است.

## محدودیت‌ها

- IndexedDB دائمیِ تضمین‌شده نیست. خروجی گرفتن از داده‌ها در مرحله پایداری اضافه می‌شود.
- پوشه پروژه داخل OneDrive است و ممکن است `node_modules` را کند یا قفل کند.
- اعلان پس‌زمینه و همگام‌سازی بین دستگاه‌ها در این نسخه وجود ندارد.
